# N-Body Simulation
This is a basic example of Newtons Law of Universal Gravitation. 
Although it is not 100% true to the law, it serves as a good example.

Currently this is On^2, however eventually I will use the Barnes Hut N-Body optimization when I have time to learn it. 

Every body exerts gravitational force on every other body. There is a central force keeping the items on screen, as they just kind of wander like a real galaxy would.

The reason this is not true to the law, is im not using the true gravitational constant, nor any velocity or mass of a specific measurable unit, rather they are just random constants that made the sim work how I wanted.
